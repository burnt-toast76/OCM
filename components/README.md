# Components

This is the **component** layer — the first of OCM's three context layers (ADR-0017): what
each part is, transcribed from its datasheet.

Purchasable parts, transcribed from datasheets under the zero-assumption rule (ADR-0014).
One directory per component; validate against spec/schema/ocm-component-1.0.schema.json.
Modules reference these via their `components:` list.
